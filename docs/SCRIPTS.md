# Analysis scripts

**Author:** Md Tariqul Islam
**Affiliation:** Laboratory of Professor Wei Hsu, The ADA Forsyth Institute, Somerville, MA, USA
**Project:** Gpr177/Wntless (WLS) and Wnt/Hedgehog genes in human dental pulp stem cells (DPSCs)

Every R script starts with a standard header: title, author, affiliation, purpose, inputs, outputs, usage, dependencies and a development note. The code follows the [tidyverse style guide](https://style.tidyverse.org/) and was formatted with the `styler` package.

## Discovery analysis: `dpsc-wls-human-scRNAseq` (GSE164157, 5 donors)

| Order | Script | What it does |
|---|---|---|
| 1 | `scripts/02_download_GEO.R` | Downloads the GSE164157 count matrices from GEO |
| 2 | `scripts/04_QC.R` | Filters cells: genes > 200, UMIs > 500, mitochondrial < 20% |
| 3 | `scripts/05_clustering.R` | Normalisation, variable genes, PCA, first clustering |
| 4 | `scripts/06a_batch_doublets.R` | Doublet removal per donor (scDblFinder); Harmony integration (20 PCs); clustering at resolution 0.5 |
| 5 | `scripts/06_annotation.R` | Cell-type labels from marker-panel module scores; mesenchyme re-clustered (Harmony dims 1–15, resolution 0.4); candidate DPSCs (stem score > 0) |
| 6 | `scripts/07_WLS_expression.R` | % WLS⁺ cells per donor and group; edgeR quasi-likelihood pseudobulk (~ donor + group); lme4 mixed model |
| 7 | `scripts/07b_WLS_sensitivity.R` | Four DPSC definitions; depth-adjusted WLS–WNT co-expression; per-donor QC |

## Coding conventions

- **One script per analysis stage,** numbered in run order; each reads the previous stage's output and writes to its own `results/` folder.
- **Settings in one place:** thresholds and dataset settings live in `config/validation_datasets.yaml`; shared code lives in `R/wls_validation_functions.R`.
- **Style:** tidyverse style guide (snake_case names, two-space indentation, spaces around operators, lines up to 120 characters), applied with `styler`.
- **Reproducibility:** fixed random seed (`set.seed(2026)`); package versions locked with `renv`; code version-controlled on GitHub.
- **Data:** raw downloads and `.rds` objects are not committed; every result can be regenerated by running the scripts in order.
